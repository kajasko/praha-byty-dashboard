What this page is

A live shortlist of Prague flats we’re evaluating for Dad (to live in) and for investment (long-term rent). Photos and prices come from the listing sites; the decision status lives in Airtable.

  1. What now — only flats verified live today that need a call or viewing. Dead ads never appear here.
  2. Cards — tap Open listing for the original ad. Dad / Invest scores help compare (when filled).
  3. Filters — switch What now / Dad focus / Investment. Language: EN by default, CS available.
  4. Updates — refreshed on weekdays from Airtable. If a card looks wrong, refresh tomorrow after the morning rebuild.

Not a real-estate agency site — a private decision board for the family.
